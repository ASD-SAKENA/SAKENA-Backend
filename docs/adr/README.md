# Architecture Decision Records

Short records of decisions that were expensive to make and would be expensive
to reverse. Each one states the problem, what we chose, and — most usefully —
what we gave up.

They are written after the decision holds up in code, not before, so a record
here describes the system as it is rather than as it was once planned.
